# Credit Card Transaction Analysis Dashboard

## Project Overview
An interactive Power BI dashboard developed to analyze credit card transactions, revenue, transaction amount and interest trends.

## Tools Used
- Power BI
- Power Query
- DAX
- Data Modeling
- Data Visualization

## Key Analysis
- Revenue and transaction analysis
- Quarterly performance analysis
- Card type analysis
- Card chip type analysis
- Customer segmentation
- Education and job type analysis
- Expenditure type analysis

## Key Metrics
- Total Revenue: 55M
- Transaction Amount: 45M
- Interest: 8M
- Transaction Count: 656K

## Dashboard
Interactive Power BI dashboard with KPI cards, slicers and visualizations.
